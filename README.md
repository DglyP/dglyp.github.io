This is the Mashup Provided for the Purdue-Unal IronHacks 

In this Application I made use of:

1. The Climate Data Online NCDC Dataset
2. Data from de CityofChicago Datasets like:
    *Parks near University of Illinois Dataset
    *Police Stations Dataset
    *Boundaries in Chicago Dataset
    *Hospitals in Chicago Dataset
    *Affordable Rental Houses Dataset
    
This application is focused in giving Illinois students an easy way of finding a place to rent.

The University of Illinois is marked with a special icon related to the IronHack.

C3.js was used to make some rain precipitation and snow graphs related to the weather in Chicago and Google Maps was used to show this information.

Finally, The app is up and running at dglyp.github.io as requested

App was tested using Firefox and Google Chrome.

Scores arrived a little late so not so many changes could be made to the app during the hackathon
